# 📄 Resume Analyzer

Analyze resumes intelligently using NLP and get skill-based course suggestions.

## 🚀 Features
- Extracts skills, education, and experience from resumes (PDF/DOCX)
- Suggests improvement courses using `courses.py`
- Modern Flask web UI with clean design
- Simple deployment-ready structure

## 🛠️ Tech Stack
- Python, Flask
- Spacy / PyPDF2 / docx
- Bootstrap 5 (for front-end styling)

## 📦 Setup Instructions
1. Clone repo
2. Create virtual environment
3. Install dependencies
4. Run Flask server
